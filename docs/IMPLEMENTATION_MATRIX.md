## Cross-phase definition of done

Every externally visible state has loading, empty, denied, unavailable, retryable failure, and terminal failure behavior where applicable. APIs have versioned contracts and structured errors. Database changes are forward/backward deployment compatible. Feature flags default experimental native paths off. Telemetry and logs pass the privacy field allowlist. Product copy distinguishes browser fallback, experimental native support, and implemented support.

An item can move from experimental to implemented only when its automated tests pass, required physical hardware coverage is recorded with build identifiers, known limitations appear in release notes, and fallback behavior is verified. A mocked capture source proves orchestration but cannot satisfy a native capture acceptance gate.
